# 📚 Comic Manager 

**Comic Manager** es una aplicación de consola que permite gestionar cómics y usuarios 📖🦸‍♂️  
Incluye funcionalidades como la gestión de usuarios, administración de cómics y asignación de cómics a usuarios



## ✨ Características principales

➟ **Gestión de usuarios** (Alta, búsqueda, eliminación)  
➟ **Gestión de cómics** (Añadir, listar, eliminar)  
➟ **Zona privada** para cada usuario  
➟ **Zona pública** con información general  
➟ **Búsqueda avanzada** de cómics  


# 🛠️ Tecnologías utilizadas
💻 **C# y .NET**
🎨 **Spectre.Console** (Interfaz visual en consola)
📂 **JSON** para almacenamiento de datos


# 🛠️ Mejoras futuras
Implementación de una base de datos en lugar de JSON
Creación de una versión con interfaz gráfica
Integración con APIs para obtener información de cómics en tiempo real
